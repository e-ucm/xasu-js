# How-to guides

A how-to guide is a **recipe for one task**. It assumes you already know the domain — what a
completable is, what an LRS is — and that you are looking for the exact calls that accomplish
something.

If you are new here, start with the [tutorials](../tutorials/README.md). If you want to know *why*
something works this way, read the [explanation section](../explanation/README.md).
